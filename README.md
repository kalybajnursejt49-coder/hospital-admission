# Hospital Admission

Консольное приложение для приёма пациента. Регистрация, назначение койки и оборудования, лабораторный и аптечный заказы связаны через `AdmissionFacade` и сохраняются в SQLite.

Требуются Java 17+ и Maven.

Первый запуск из чистой папки: `mvn compile exec:java`

После сборки: `mvn exec:java`

Тесты: `mvn test`

Проверка покрытия: `mvn verify`

Отчёт JaCoCo находится в `target/site/jacoco/index.html`. База данных по умолчанию — `data/hospital.db`. Страховой номер должен начинаться с `INS-`, например `INS-100`. По умолчанию в отделении `GENERAL` есть 3 свободные койки, в `ICU` — 1, а препарата `paracetamol` — 5 единиц.

Таблица `admission_chain` хранит состояния `PENDING_B`, `PENDING_C`, `COMPLETED` и `COMPENSATED`. При запуске незавершённые цепочки откатываются по данным SQLite. В меню можно обнулить койки или запас препарата и показать сбои этапов B и C.
